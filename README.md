# 新作者成长识别

维护新作者成长信号、复核结论和扶持效果的资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括作者档案、作品信号、统计窗口、候选结论、反作弊结论、复核意见、扶持动作、名单快照、申诉记录，状态示例为观察中 → 候选 → 待复核 → 已入选 → 申诉中 → 已结束。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

资料按统计窗口保存七类信号（`window_signals`）：作者起始时间、作品主题、原创状态、有效观看、主动推荐、负反馈、扶持动作。同时声明六条产品策略（`policies`）：

- `comparison`：领域规模不同不能直接比较，须在同一内容领域内归一化后再排序
- `history`：删除作品、异常流量、账号合并、规则换版不得改写历史判断，只追加更正记录
- `review`：候选名单须经反作弊筛查与人工复核全部通过后方可入选
- `transparency`：作者可查看影响自身结论的主要依据并申诉，他人私密数据不可见
- `snapshot`：每期名单保留数据快照，运营人员可重现该期名单
- `evaluation`：扶持效果看扶持前后的持续创作与受众留存，不以单次涨粉为成长结论

已整理的业务事实：

- 年轻新作者成长速度显著高于同类创作者
- 主动推荐可以反映用户认可
- 平台会针对不同阶段作者提供成长扶持
- 部分入驻不足一年的专业作者在小圈层持续被主动推荐，但因粉丝基数小未能进入统一扶持名单
- 部分账号因单次热点暴涨后迅速沉寂，单次涨粉不代表持续成长

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明。后续服务应继续兼容这份公开资料约定。
