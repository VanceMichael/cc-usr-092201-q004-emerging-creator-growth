# 新作者成长识别

维护新作者成长信号、复核结论和扶持效果的资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括作者档案、作品信号、统计窗口、候选结论、复核意见、扶持动作，状态示例为观察中 → 候选 → 待复核 → 已入选 → 申诉中 → 已结束。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 年轻新作者成长速度显著高于同类创作者
- 主动推荐可以反映用户认可
- 平台会针对不同阶段作者提供成长扶持

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明。后续服务应继续兼容这份公开资料约定。
