# 新作者成长识别

维护新作者成长信号、复核结论和扶持效果的资料。领域设计见 `docs/design.md`。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。记录类型覆盖作者档案、作品信号、统计窗口、领域基准、候选结论、反作弊结论、复核意见、扶持动作、效果评估、申诉记录、数据快照、账号血缘事件；流程状态为观察中 → 候选 → 待复核 → 已入选 → 扶持中 → 已结束，申诉中可由候选、待复核、已入选进入。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 年轻新作者成长速度显著高于同类创作者
- 主动推荐可以反映用户认可
- 平台会针对不同阶段作者提供成长扶持
- 领域规模差异大，信号须先与同期同领域基准比较，不直接跨领域比较绝对量
- 成长结论须跨多个统计窗口持续成立，单次热点暴涨不构成成长
- 统计窗口关闭后不可改写，删除作品、异常流量、账号合并、规则换版均以追加记录处理
- 每期名单绑定数据快照与规则版本，可按原快照原规则重现
- 作者仅可查看影响自身的主要依据并申诉，不可见他人私密数据

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明，并校验关键记录类型（统计窗口、领域基准、数据快照、申诉记录等）与申诉流程状态不被移除。后续服务应继续兼容这份公开资料约定。

```
python3 -m unittest discover -s tests
```
